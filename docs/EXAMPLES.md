# Ejemplos de uso

Estos prompts son puntos de partida. Añade el público, la tarea principal, las restricciones y el resultado que esperas.

## Rediseñar una interfaz existente

```text
Usa frontend-studio para mejorar este panel de seguimiento.
El usuario necesita comparar cuatro períodos y encontrar registros rápido.
Conserva los filtros y las acciones actuales.
Mantén la tipografía, el logo y la paleta existentes.
Implementa la propuesta y revisa escritorio y móvil.
```

Resultado esperado: cambios implementados, explicación de decisiones, revisión visual y limitaciones pendientes.

## Comparar direcciones

```text
Usa frontend-directions para proponer tres enfoques para un catálogo cultural:
uno editorial, uno centrado en imágenes y uno pensado para explorar categorías.
Usa el mismo contenido en los tres.
Muéstrame las diferencias de composición y navegación antes de implementar.
```

Resultado esperado: alternativas con diferencias sustanciales; no tres cambios de color de la misma plantilla.

## Investigar referencias

```text
Usa godly-inspiration para buscar referencias de una web de arquitectura.
Necesitamos destacar las fotografías y facilitar el acceso a los proyectos.
Comparte las fuentes y explica qué decisiones adaptarías a nuestro contenido.
```

Resultado esperado: referencias trazables y decisiones aplicables, sin reproducir diseños ni recursos ajenos.

## Hacer un ajuste puntual

```text
Reduce el espacio entre la portada y la sección siguiente.
Conserva las funciones y revisa que el título siga legible en móvil.
No hace falta explorar nuevas direcciones visuales.
```

Resultado esperado: una edición acotada. Las skills no deben ampliar innecesariamente el trabajo.

## Trabajar sin complementos

```text
Usa frontend-studio con las skills disponibles.
Si falta alguna skill externa, indícalo y continúa con el brief y el sistema visual.
No instales dependencias automáticamente ni afirmes haber usado herramientas ausentes.
```

## Documentar funciones nuevas

```text
Mejora el diseño y la navegación de esta página.
Al terminar, separa los cambios visuales de las funciones nuevas.
Indica qué acciones funcionan localmente y cuáles requieren un backend.
```
