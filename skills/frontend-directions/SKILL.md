# Frontend Directions

Use this for design exploration. Inspired by the asset-first and visual-variation workflow in https://github.com/alchaincyf/huashu-design; adapt it to the user's requested scope.

Inspect existing brand assets, product imagery, content, and design system before proposing directions. For a named real brand, verify its current assets from an authoritative source when necessary. Distinguish facts from placeholders.

Create two or three materially different visual directions when alternatives would help the user decide. Vary composition, visual hierarchy, typography, or interaction rather than offering small color swaps. Whenever practical, make the options viewable as rendered sketches or prototypes. Explain what each direction optimizes for.

If the user asked to choose a direction, present the options for their choice. If they asked for a finished frontend, use the exploration internally or show a brief comparison, choose the strongest fit, and continue to a completed implementation. Avoid mandatory three-option gates for every request.
