# Contribuir

1. Describe el problema concreto que quieres resolver y un prompt que lo reproduzca.
2. Propón un cambio pequeño en la skill correspondiente.
3. Prueba el flujo en una interfaz genérica y explica qué verificaste.
4. Actualiza la documentación y el historial si cambia el comportamiento.
5. Abre un pull request con el cambio y sus limitaciones.

Mantén las instrucciones breves, evita dependencias obligatorias innecesarias y conserva la prioridad del brief del usuario.

No adjuntes información de clientes ni material interno. Si aportas instrucciones o recursos de terceros, identifica su fuente y licencia. Las contribuciones aceptadas se incorporan bajo la licencia MIT de este repositorio.
